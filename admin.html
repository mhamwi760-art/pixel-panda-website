Log in to edit your website

The dashboard saves your changes straight to your GitHub, and the live site updates about a minute later. To log in, paste your GitHub key. You only do this once per device.

How to create your key (one time, about 2 minutes)
  1. Open github.com → Settings → Fine-grained tokens → Generate new token (signed in as mhamwi760-art).
  2. Token name: The Panda Paw dashboard. Expiration: pick a date (for example 1 year).
  3. Repository access: choose Only select repositories and select pixel-panda-website.
  4. Permissions → Repository permissions → Contents: choose Read and write.
  5. Press Generate token, copy it (it starts with github_pat_) and paste it below.

Keep the key private, like a password. It can only change this one website. If you ever lose a device, delete the key on that same GitHub page.
